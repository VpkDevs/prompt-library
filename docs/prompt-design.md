# Prompt design guide

Effective prompts in this library share a few traits:

- **Context**: define the role, domain, and intended audience.
- **Inputs**: name each required input and keep placeholders explicit.
- **Output contract**: specify sections, format, or schema where useful.
- **Boundaries**: state what the model should not infer or fabricate.
- **Evaluation hooks**: include criteria that make outputs easier to review.

Use this guide when adding new prompts or reviewing existing ones.
